# Site tamtui.com

Site de TAMTUI SAHEL, société experte fournisseur (Niamey, Niger), avec deux pôles :

- `index.html` : accueil du groupe (les deux pôles, la société, le contact) ;
- `agri.html` : pôle Agri-numérique, en vert (application mobile TAMTUI, logiciels de gestion, tarifs) ;
- `fournitures.html` : pôle Fournitures & services, en chocolat (matériel informatique et bureautique, consommables, objets publicitaires, matériel industriel, prestations).

Pages statiques sans dépendance, publiées avec GitHub Pages (branche `main`, dossier racine). Les photos (`assets/photos`) viennent de la plaquette commerciale de la société.
La page de téléchargement des logiciels reste sur https://tamtui.github.io/TAMTUI-TELECHARGEMENTS/ (dépôt séparé).
Ce dépôt est public : il ne contient ni code des logiciels, ni clé, ni donnée de clients.
