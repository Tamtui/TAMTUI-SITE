# Site tamtui.com

Site vitrine de TAMTUI SAHEL : l'application mobile TAMTUI pour les producteurs et les logiciels de gestion TAMTUI pour les organisations.

- Page unique, sans dépendance : `index.html` et `assets/`.
- Publié avec GitHub Pages (branche `main`, dossier racine).
- La page de téléchargement des logiciels reste sur https://tamtui.github.io/TAMTUI-TELECHARGEMENTS/ (dépôt séparé).
- Ce dépôt est public : il ne contient ni code des logiciels, ni clé, ni donnée de clients.
